Goal

Build a mobile-first, embeddable Brand Archetype Quiz web app that calculates Primary + Secondary archetypes and gates results behind a simple form (first name + email). Include 3 visual break screens using the provided Tenor GIF links, Meta Pixel tracking, and a social share button.

Inputs Provided





Quiz feed (questions + scoring): Use the separate document titled "Brand Archetype Quiz: Questions & Scoring (Replit Feed)".



Archetypes (canonical 12): Ruler, Hero, Magician, Outlaw, Explorer, Creator, Lover, Caregiver, Everyman, Jester, Sage, Innocent.

Scoring Rules





Each question has 6 answers. Each answer awards points to two archetypes.



Weighting by phase:





Q1–Q7: 3 points to each of the two archetypes



Q8–Q14: 2 points to each of the two archetypes



Q15–Q18: 1 point to each of the two archetypes



Output:





Primary archetype: highest total points



Secondary archetype: second-highest total points



Tie-breaker: if tied, prefer the archetype with the higher total from Q1–Q7; if still tied, use a fixed priority list (Ruler, Hero, Magician, Outlaw, Explorer, Creator, Lover, Caregiver, Everyman, Jester, Sage, Innocent).

Fields: First name, Email



Validate email format.



Submit should POST to GoHighLevel webhook (URL will be provided by owner after GHL setup).

GoHighLevel Webhook & Custom Fields

The app will POST a JSON payload to a GHL webhook with the following data structure:

{
  "first_name": "string",
  "email": "string",
  "primary_archetype": "string (archetype name)",
  "primary_score": "number",
  "secondary_archetype": "string (archetype name)",
  "secondary_score": "number",
  "tag": "string (format: quiz_primary_{primary_archetype_lowercase})",
  "answers": "string (formatted list of all 18 Q+A pairs, e.g., 'Q1: [answer text]\\nQ2: [answer text]\\n...')"
}

Owner will map these fields in GHL workflow to:





brand_archetype_quiz_highest_category_name ← primary_archetype



brand_archetype_quiz_highest_category_score ← primary_score



brand_archetype_quiz__secondary_category_name ← secondary_archetype



brand_archetype_quiz__secondary_category_score ← secondary_score



Tag: quiz_primary_{primary_archetype_lowercase}



Note: answers field

On successful POST: show confirmation screen with primary + secondary results.
